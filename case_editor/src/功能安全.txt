故障传输
收集算法（感知、定位等传感器故障）、通信故障、底软故障，经 alarm driver 聚类后传至仲裁模块。
仲裁模块将降级；alarm 通过上行链路传回故障管理模块，给 SoC 做降级。

ComAdaptor
MCU 侧提供整车状态给仲裁和 L2APA，可以对上层算法信号进行截断控制。

ADAS Check 模块（仲裁模块）

com adaptor driver
进行通信校验，检测报文侧的 RC、checksum 和超时。

IMU driver

alarm driver
接收故障管理 topic 透传给 ADAS Check；
接收上行数据映射到 MCU error topic 发出；
进行通信校验，通过 event trigger 发通讯校验失败故障到 MCU 侧。

MCU 故障中间件
收集故障上报，维护故障状态表。


算法故障
指智驾算法模块在运行过程中出现的异常故障，主要包含以下子故障：

1. 算法节点输入数据异常
   DR（行位算法）输出 NULL 值、异常值、数据超时等；
   VisionFusionTracking 输出 NULL 值、异常值、数据超时；
   前雷达目标 NULL 值、异常值、数据超时；
   角雷达目标 NULL 值、异常值、数据超时；
   车道线 NULL 值、异常值、数据超时；
   图像超时、图像乱序、图像不同步等。

2. 算法内部逻辑异常
   目标融合数据转换故障；
   目标融合内部异常监控故障；
   参数配置读取/校验故障；
   动静态目标距离范围合理性检查不通过；
   动静态目标距离合理性检查不通过；
   动静态目标速度合理性检查不通过。


通信故障
指系统各组件之间、系统与外部设备之间的通信链路异常故障。

1. 片间通信校验异常
   RC 连续丢帧、乱序；
   CRC 连续校验错误；
   数据超时。

2. 报文丢失、无效，报文校验失败，总线关闭等。


底软故障
指底层软件及硬件层面的异常故障。

1. 供电类故障
   蓄电池供电电压高于/低于工作阈值。

2. 存储配置类故障
   下线 NVM 无配置信息。

3. 硬件故障类故障
   域控 MCU 过温故障；
   气囊 IMU 数据异常；
   气囊 IMU 未标定；
   气囊 IMU 时间同步异常；
   气囊 IMU 数据 E2E 校验失败。

4. MCU 硬件类故障
   锁步核检测到异常；
   总线读写非法地址；
   cache 出现不可纠错误；
   MCU 内部模块安全触发器不可纠错误；
   内存 ECC 错误；
   内部总线错误等。


NVM 定义
NVM 全称为非易失性存储器（Non-Volatile Memory），是智能驾驶域控 MCU 的核心存储组件，用于存储车辆车型专属配置、标定参数、系统固件等关键信息，具备断电后数据不丢失的特性，是域控正常运行的基础硬件支撑。

下线 NVM 无配置信息故障说明
该故障指车辆生产下线环节，未将车型专属的有效配置信息写入域控的 NVM 中，属于非执行器类故障，会直接影响 ADAS 功能正常运行。

故障触发条件：域控上电后检测到以下任一情况即判定为该故障：
配置文件前 249 字节为 0x00，最后一个字节为 0xFF
配置文件不满足 CRC 校验（全 0xFF 或全 0x00）
配置文件不满足车型有效性校验（车型代码为全 0x00 或全 0xFF）

故障影响：触发该故障后，ACC、AEB、ICC、APA、RPA 等 ADAS 功能会触发降级，部分功能会直接退出，无法正常使用。

故障标识：对应故障码 DTC 为 ACE655，告警 ID 为 20057-0，故障 ID 为 0x00075E97。
