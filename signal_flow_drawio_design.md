# 信号流程控制框图设计（Draw.io风格）

## 1. 基础框图元素定义

### 1.1 框图形状定义

| 元素类型 | 形状 | 颜色 | 说明 |
|---------|------|------|------|
| **Set Signal** | 圆角矩形 | 绿色 (#90EE90) | 设置/发送信号的操作 |
| **Check Signal** | 菱形 | 蓝色 (#87CEEB) | 检查/判断信号状态 |
| **Wait** | 平行四边形 | 黄色 (#FFD700) | 固定时间等待延迟 |
| **Timeout** | 六边形 | 橙色 (#FFA500) | 超时控制器 |
| **Duration** | 双线矩形 | 紫色 (#DDA0DD) | 持续检测时间段 |
| **Async Task** | 圆柱体 | 青色 (#40E0D0) | 异步执行任务 |
| **Decision** | 菱形 | 灰色 (#D3D3D3) | 条件判断节点 |
| **Start/End** | 椭圆 | 深灰 (#708090) | 开始/结束节点 |
| **Process** | 矩形 | 白色 | 一般处理过程 |

### 1.2 连接线定义

| 连接类型 | 线型 | 箭头 | 说明 |
|---------|------|------|------|
| **顺序流** | 实线 | 实心箭头 | 正常的顺序执行 |
| **条件流** | 实线 | 实心箭头 + 标签 | 带条件的分支（是/否） |
| **超时触发** | 虚线 | 空心箭头 | 超时触发的流程 |
| **异步调用** | 双线 | 双箭头 | 异步并行执行 |
| **返回流** | 点线 | 实心箭头 | 循环返回 |
| **数据流** | 细实线 | 小箭头 | 数据传递 |

## 7. Draw.io使用建议

1. **创建新图**：在draw.io中选择"空白图"
2. **使用形状库**：从左侧形状库选择相应形状
3. **应用配色**：右键形状 → 编辑样式 → 设置填充和边框颜色
4. **连接线**：使用"连接器"工具连接各个框
5. **分组**：将相关元素分组便于移动和管理
6. **对齐**：使用顶部工具栏的对齐工具整理布局
7. **导出**：完成后可导出为PNG、SVG、PDF等格式

这个设计可以直接作为draw.io绘图的参考模板！
